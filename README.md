# Data Engineering Portfolio Workspace

Welcome to my central data engineering repository. This workspace showcases end-to-end cloud pipelines, big data processing layouts, and automated serverless architectures.

## 📂 Active Production Pipelines

* **[E-Commerce Pipeline](./E-Commerce):** An end-to-end serverless OLTP-to-OLAP pipeline simulating retail transactional traffic, handling streaming file-discovery ingestion via AWS Lambda, and structuring data into an analytical PostgreSQL Star Schema using strict UPSERT idempotency.
* **[NYC Taxi Pipeline](./NYC_Taxi_Pipeline):** A big data processing framework featuring modular infrastructure automation via Terraform, cloud data collection via Lambda, and distributed analytical data transformations using AWS Glue and PySpark.
